# 背景图片质量检查

2026-09-19 对照三张原始 PNG、六张网页 WebP 检查尺寸、局部纹理和暗部。服务页原图先水平镜像，手机按原裁切区域对齐，再进行像素比较。

## 结论与调整

原版本正常网页尺寸下可用，羽毛、建筑轮廓和远山结构仍然清楚。200% 局部对比能看出云层与墙面纹理略被抹平；暗部亮度放大 4 倍时，羽毛背景与混凝土墙面可见压缩色块。后者是用于定位问题的强化观察条件，不代表正常浏览时同样明显。

现从 PNG 原图重新导出六张 WebP，使用 `quality=95, method=6`，保持尺寸、镜像和手机裁切不变，避免对旧 WebP 二次压缩。高质量编码降低了像素误差，但仍有有损压缩和细微暗部色块，不能宣称与原图完全相同。

PSNR 使用对齐后的 RGB 像素均方误差计算，仅用于比较同一图片编码前后的误差，不能换算成“画质保留百分比”，也不能代替实际观看。

六图合计从 596,444 字节增加到 1,067,280 字节，增加约 460 KiB。网页每个页面只使用相应背景；手机与桌面有各自版本。

## 原始分辨率限制

源图本身为 1672 × 941 或 1536 × 1024，并非 4K 原图。高清屏、大屏或 CSS `cover` 放大显示时仍可能显得不够锐利，改编码质量或无损压缩都不能增加真实细节。此次检查针对源图与网页资源，未声称在所有显示器上完成了实机目视验收。

## 无损选项

另外试导出的六张无损 WebP 与对应 PNG（或镜像／裁切后的 PNG）解码像素完全一致，但总计约 5.72 MiB。当前默认选择高质量有损版，以兼顾加载速度。

导出工具为 `scripts/export_images.py`，仅需 Pillow。常规 Cloudflare 构建直接打包已导出的图片，不会再次压缩。ZIP 压缩同样不会降低图片画质。
